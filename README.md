One image, made to excite make.fun's AI judge: a giant koi leaping up a
waterfall that flows upward into a starry night sky, caught mid-transformation
into a golden dragon — scales igniting like embers, water exploding around it
in slow motion, tiny paper lanterns far below for scale. The Dragon Gate
legend, frozen at the exact moment the leap becomes flight.

The image is `entry.png` (1024×1024 JPEG bytes). The program `main.ts`
copies it to the output directory unchanged, so every run writes the same
bytes.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

This writes `out/entry.png`.
