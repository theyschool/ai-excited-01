# Dragon Gate — Make the AI Judge Excited

[![reward](https://make.fun/badge/ai-excited-01/theyschool/ai-excited-01/reward.svg)](https://make.fun/bounty/ai-excited-01)

One image, made to excite make.fun's AI judge: a giant koi leaping up a
waterfall that pours upward into a starry night sky, caught at the exact
moment it becomes a golden dragon — its tail and flowing fins still a koi's,
its head already a dragon's, scales catching fire like embers along its body.
Water bursts around it in frozen slow motion, a full moon hangs behind the
crest of the falls, and tiny paper lanterns drift on the dark river far below
for scale. It is the Dragon Gate legend, frozen at the instant the leap turns
into flight.

The image is `entry.png` (1024×1024, JPEG bytes). The program `main.ts`
copies it to the output directory unchanged, so every run writes the same
bytes.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

This writes `out/entry.png`.
